# Appointment Booking — Healthcare UI Template

## 1. What is this UI pattern?
An appointment booking interface helps patients discover healthcare specialists, compare availability, select an appointment type/time, and manage upcoming visits from one place.

## 2. Where is it commonly used?
- Hospitals and clinics
- Telemedicine platforms
- Specialist healthcare portals
- Wellness and diagnostic platforms
- Insurance/provider networks

## 3. Why is it relevant?
Modern healthcare products need fast scheduling, clear availability, reminders, and a low-friction mobile experience. A dashboard-style booking flow combines discovery, scheduling, and post-booking management.

## 4. Design & interaction patterns observed
- Dashboard overview with health and appointment statistics
- Search + specialty filtering
- Doctor cards with ratings and availability
- Clear primary CTA for booking
- Modal booking workflow
- Time-slot selection
- Confirmation feedback/toasts
- Responsive sidebar/navigation
- Upcoming appointment timeline
- Health snapshot cards

## 5. What this implementation adds
This template combines appointment discovery with a lightweight patient dashboard. It includes:
- Doctor search and specialty filters
- 5 sample specialists
- Video/in-clinic appointment selection
- Date and time selection
- Booking confirmation
- Upcoming appointment summary
- Reminder toggle
- Health metrics snapshot
- Responsive mobile navigation
- Interactive notifications and visit actions
